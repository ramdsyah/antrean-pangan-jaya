# Antrean Pangan Jaya — Android source

Project Android native untuk menyimpan beberapa profil penerima manfaat dan membantu pengisian formulir resmi.

Data profil: Nomor KK, NIK, nomor kartu ATM, tanggal lahir (YYYY-MM-DD).
Wilayah, gerai, CAPTCHA, dan disclaimer tetap dipilih/diisi manual. Aplikasi tidak mengirim pendaftaran otomatis.

Buka folder ini dengan Android Studio, tunggu Gradle Sync, lalu jalankan ke perangkat Android atau emulator.
Ini source project, bukan APK siap instal. Website dapat mengubah struktur kolom sehingga fitur pengisian perlu diuji.
Website resmi: https://antrianpanganbersubsidi.pasarjaya.co.id/
